# Quarterly access review procedure

Every quarter, the security operations team reviews privileged access for production systems. The procedure has been run for three years and is expected to continue indefinitely.

The reviewer compares the current access ledger with the owner roster, records discrepancies, requests human approval for proposed removals, and stores evidence for the next audit. The procedure changes only when the access policy changes, normally once or twice per year.

Automation must remain advisory: it may summarize evidence and propose findings, but it must never approve, revoke, grant, or sign access changes.
